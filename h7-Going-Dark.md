### 7 Things You Should Know About Tor https://www.eff.org/deeplinks/2014/07/7-things-you-should-know-about-tor

- Tor still works
- According to slides released by the Guardian in 2013 the NSA was at least at the time not yet able to break anonymity provided by Tor
- Most effective attacks have not been on Tor itself but came through browser bugs and misconfiguration by the user
- On a cryptographic level tor has not been broken
- Tor is not only used by criminals but also used by them
- It's used by activists to circumvent censorshipt and get anonymity
- military institution use it for secure communication and planning
- Journalists use it to securly talk to sources
- There is no military back door
- Originally funded by the US Navy
- It has been audited by cryptographers and security professionals
- no one has been prosecuted for running a tor relay in the united states up to that point
- No one has even been sued for operating such a relay
- If you act in a criminal way you can still be charged and prosecuted
- Tor is easy to use
- A browser bundle is available
- Its preconfigured in a secure way
- Tor is not as slow as its reputation
- It is slower than a normal internet connection but a lot of time has been invested to make it as fast as possible
- Tor is not foolproof
- If used incorrectly you are not anonymous
- If an adversary sits on both ends of the communication they can still identify you

 ### Hiding behind the Keyboard (Brett Shavers, John Bair, 2016)

 - Book focuses on the technical aspects of covert communication in the context of forensic analysis of cyber crime
 - The intended audience for the book is law enforcement, criminal investigators and civil investigators
 - It tries to stay relevant by focusing on concepts and principles more than any one specific technology
 - The Onion Router (Tor) has had one of the biggest impacts on anonymity on the internet
 - Based on the browser FireFox Tor hides a user's real IP address making it almost impossible to identify any one specific user
 - Tor is used by both legitimate user's such as activists, whistleblowers and even businesses but also by criminals and terrorists
 - Tor uses 3 separate layers of encryption to connect through three randomly chosen relay's
 - Each relay removes one layer of encryption
 - The only information a relay can see is the encrypted data, where it came from and where to send it to next
 - The biggest weakness of the Tor browser is the user
 - The best thing a Tor user can do is not change any settings, as the browser is already set up with security in mind
 - A user that allows scripts and plugins to be installed and run risks leaking their real IP-address to that plugin or script
 - Man-in-the-middle attacks are feasable but for the most part only for nation state actors and even then chances on compromising Tor are low
 - The ressources required to investigate within the Tor network usually are prohibitive enough that this type of investigation is only done in special cases
 - The ultimate goal is always to capture the real IP-address of a target to then use traditional investigative methods
 - Phishing the target can be one of the ways to obtain the true IP-address
 - Another method is using OSINT techniques on the open web to identify a darkweb user based on limited details such as an e-mail address or username
