## Task X - OWASP

### A01:2021 – Broken Access Control 

Access control is about who can access data and who can not. A classic access control is a login for a website with username and password.
Access control is broken when a user has access to data they shouldn't have. For example a basic user has access to administrator tools or 
an anonymus user has access to areas that only authenticated users should have access to

### A03:2021 – Injection 

Injection uses normal input fields to interact with the underlying computer system, by abusing the input field to send code snippets to the host.
SQL injection is a classic attack that falls under this category. A system is vulnarable to injection when it, for example, does not sanitize the user input send through these fields.


### A05:2021 – Security Misconfiguration

This category is quite broad. It covers things like mis- or unconfigured security features, istalling or enabling of unnecessary features, providing too much information
in an error message, as well as software that is out of date. 

### A06:2021 – Vulnerable and Outdated Components

The category is what it sounds like. The code or the software stack uses components that are known to be vulnarable. 
This can happen by updates not being installed or vulnarable current versions
